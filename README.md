# Gapify

Site institucional da Gapify, uma agência de criação de sites prontos e soluções digitais para comércios de pequeno, médio e grande porte.

## Páginas

- `index.html` - Página inicial
- `about.html` - Sobre a agência
- `services.html` - Serviços oferecidos
- `contact.html` - Formulário e informações de contato

## Como executar

Abra `index.html` diretamente no navegador ou use a extensão Live Server do VS Code.

O projeto é estático e não precisa de instalação de dependências.

## Tecnologias

- HTML5
- CSS3
- JavaScript
